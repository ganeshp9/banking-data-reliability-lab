# Establish CI, documentation, and a reproducible release

## Objective

Make the first release understandable, testable, and reproducible for a
technical reviewer.

## Acceptance criteria

- [ ] CI runs formatting, linting, type checks, and automated tests.
- [ ] Local setup and demonstration complete in 15 minutes or less on the documented environment.
- [ ] Architecture, contracts, decisions, limitations, and recovery steps are documented.
- [ ] Secrets scanning and dependency review are configured.
- [ ] A clean clone can reproduce the demonstration with synthetic data only.
- [ ] The release includes evidence for every stated success criterion.

## Out of scope

Production readiness, regulatory compliance, and unsupported benchmarks.
