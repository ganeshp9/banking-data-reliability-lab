# Add reconciliation and observability

## Objective

Give operators clear evidence of pipeline state, freshness, check results, and
source-to-curated reconciliation.

## Acceptance criteria

- [ ] Accepted counts and control totals reconcile exactly for clean fixtures.
- [ ] Run status, freshness, and quality results are queryable.
- [ ] Reconciliation failures block publication where appropriate.
- [ ] A failure demo shows detection, diagnosis, correction, and recovery.
- [ ] An operator runbook documents routine and failed-run procedures.

## Out of scope

An elaborate production monitoring platform or custom frontend.
